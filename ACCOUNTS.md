# Default Test Accounts

Below are the pre-configured accounts generated by `DbSeeder`.
You can use these credentials to log in and test different roles in the application.

**Default Password for all accounts:** `Password123!`

| Role | Email (Username) | Permissions / Notes |
| :--- | :--- | :--- |
| **Manager** | `manager@spa.com` | Full system access. Linked to an Employee record with Manager role. |
| **Technician** | `tech@spa.com` | Limited to Technician area. Linked to Employee & TechnicianDetail (Senior skill). |
| **Receptionist** | `reception@spa.com` | Access to Booking & Customer management. Linked to Employee record. |
| **Customer** | `customer@spa.com` | Client-facing access. Can book appointments and view history. |

## How to Reset
If you want to reset these accounts or data:
1. Drop the database or delete the specific records.
2. Restart the application.
3. The `DbSeeder` will automatically recreate them on startup.
